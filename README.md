# Last-Soldier-Another-World

Проект игры на Unity **2022.3.47f1**.

## Запуск

1. Откройте папку проекта в Unity указанной версии.
2. Для входа и таблицы лидеров скопируйте `database.local.example.txt` в `database.local.txt` в корне проекта и укажите свои реквизиты MySQL. Локальный файл исключён из Git.
3. Откройте `Assets/Scenes/Menu.unity` для регистрации и входа либо `Assets/Scenes/SampleScene.unity` для проверки игрового процесса. Запустите Play.

Для работы БД требуются таблицы `users` и `ratings` с полями, используемыми в запросах `Assets/Scripts/Bd_MySql/MySQLConnector.cs`. Внешняя база данных не входит в репозиторий.

Для Windows-сборки положите `database.local.txt` рядом с исполняемым файлом игры. Без локальной конфигурации функции базы данных покажут сообщение об ошибке.

`Assets` вместе с `.meta`, `Packages` и `ProjectSettings` входят в репозиторий. Кэш Unity, логи и сгенерированные файлы среды разработки исключены через `.gitignore`.
