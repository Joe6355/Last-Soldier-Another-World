# Тестовый APK для Android

Сборка предназначена для проверки сенсорного управления и игрового процесса на телефоне. Отдельный идентификатор приложения — `com.joe6355.lastsoldier.test`, название — «Последний солдат — тест». Сохранения локальные; они не переносятся автоматически в Яндекс Игры.

Готовый файл: `Builds/Android/last-soldier-android-test.apk`, версия **1.0.4**, код версии **5**, 60 825 732 байт (около 61 МБ). Сборка завершилась без ошибок; проверены подписи APK v1/v2, целостность архива и ARMv7/ARM64. Подпись совпадает с предыдущим APK. Отчёт — `Builds/RatingValidation/android-apk-report.json`, журнал — `merchant-prompt-android-build.log`. Unity запущена с `-job-worker-count 4`; оптимизации Burst сохранены.

10.10.2026 APK установлен через USB поверх версии 1.0.3 на телефон `23021RAA2Y`. Android подтвердил версию 1.0.4 и код 5; дата первой установки сохранилась. PlayerPrefs до и после установки совпали побайтно. Резервные копии и отчёт `merchant-prompt-phone-install.json` находятся в исключённом из Git каталоге `Builds/RatingValidation`. После установки игра запущена: процесс работает, в журнале процесса не обнаружены критические исключения Unity/Android. Телефон был в состоянии `Dozing`, показ игрового экрана не подтверждён; проверка на экране телефона остаётся ручной. Отчёт запуска — `merchant-prompt-phone-smoke.json`, журнал — `merchant-prompt-phone-runtime.log`.

В этой версии удалены старое приветствие, подписи и фиолетовые кнопки торговца. Существующая мобильная плашка «Торговец» сохранена. В Unity проверены вход/выход из зоны, открытие магазина, остановка боя и возврат в игру при закрытии, попадание касания при 854×393 и 2400×1080. Отчёт — `merchant-prompt-checks.txt`, журнал — `merchant-prompt-editor-5.log`.

Для повторной ручной установки перенести APK на телефон и открыть его. Если Android запросит разрешение на установку из этого источника, разрешить установку для приложения, которым открыт APK.

## Повторная сборка

В Unity 2022.3.47f1 нужны Android Build Support, SDK, NDK и OpenJDK. Выбрать **Tools → Last Soldier → Build Android Test APK**. Результат: `Builds/Android/last-soldier-android-test.apk`.

Профиль сборки: APK, IL2CPP, ARMv7 и ARM64, минимальный API 23, целевой API 34, OpenGL ES 3, горизонтальный экран с поворотом в обе стороны, Development Build, тестовая подпись Unity. Для Android используются отдельные defines с `LAST_SOLDIER_ANDROID_TEST`; `YandexGamesPlatform_yg` исключён, чтобы приложение не вызывало JavaScript-функции браузерного SDK. Настройки WebGL не меняются.

## Что проверить

- Плавающий джойстик слева и огонь справа двумя пальцами. Касание — автоприцел, жест — выстрел после отпускания; возврат жеста в центр отменяет его.
- Прямой выбор четырёх типов стрел и переключение купленных режимов. Удержание стреляет повторно только в купленном и выбранном автоогне.
- Рывок, щит по переключению, зелье; в меню «···» удержание зеркала до возвращения в лагерь и обзор.
- **Меню → Настроить кнопки → Расположение кнопок**: размер, прозрачность, перенос, сохранение, отмену и сброс. Второй вход — золотая кнопка в карточке «Кнопки на экране» игровых настроек.
- Рейтинг: свайпы вверх/вниз и золотой бегунок, доступность первой и последней строки, отдельный личный результат и нейтральные строки при недоступном общем рейтинге.
- Торговца, количество покупки, прокачку, достижения и арену. Камера по умолчанию — 5; обзор — 6, после отпускания — снова 5.
- Дроп с мобов: обе границы шанса увеличены на 25%; это увеличение среднего количества выпадений, без гарантии для отдельного убийства.
- Смерть, отмену тестового видео и продолжение с полным HP.
- Видео во вкладке «Бонусы»: +500 монет после завершения и 0 при отмене; награда сохраняется. В APK это тестовое видео.
- Сворачивание приложения, возвращение и сохранение после перезапуска.

При запросе рекламы появляется окно **«Тестовое видео»** или **«Тестовая реклама»**. Через три секунды доступна кнопка завершения; rewarded можно закрыть без награды сразу. Выдача награды и закрытие используют существующие callbacks YG2 и `GameMonetization`. Кнопки не управляют настоящей рекламой.

Настоящие Яндекс ID, облако, онлайн-рейтинг и реклама в APK недоступны. Отмена входа не блокирует запуск; рейтинг показывает короткий статус недоступности и строки-заглушки. Эти сервисы нужно проверять в WebGL-сборке через черновик Яндекса.

## Файлы

- `Assets/Editor/YandexBuild.cs`: повторяемая сборка APK.
- `Assets/Scripts/Yandex/AndroidTestPlatform.cs` и `.meta`: адаптер платформы и окно тестовой рекламы; компилируются только с тестовым define вне WebGL.
- `Assets/UI/ForestGarrison/Enemy/ShieldReinforcement.shader`: полная точность вычислений цвета, чтобы эффект усиления щита компилировался для Android OpenGL ES 3.
- `Builds/Android`: установочный файл; каталог исключён из Git.

Нативные callbacks и локальное восстановление проверены отдельным Windows-запуском того же тестового адаптера: старт гостем, защита от зависания входа, сенсорный интерфейс, смерть, отмена/награда видео, полный HP, монеты, покупка, попадание UI-raycast в кнопки и перезагрузка сохранения. Это не заменяет проверку Android-ввода и производительности на самом телефоне.

Предыдущая регрессия эффекта щита прошла: красится только дерево щита во всех восьми кадрах анимации и обоих направлениях. Журналы проверок: `Builds/RatingValidation/native-android-probe.txt` и `Builds/RatingValidation/android-shield-regression.log`. Новое управление, настройки и регрессия оружия проверены в Unity; отчёты — `mobile-checks.txt`, `compact-market-checks.txt`. Проверка настоящих одновременных касаний и производительности Android остаётся за тестом на устройстве.

Текущий APK включает новое [мобильное управление](MOBILE_CONTROLS.md), усиление после волны 15 и [притягивание лута](LATE_WAVES_LOOT.md). Идентификатор пакета сохранён.
