Обновлено 07.11.2026: production 1.0.6 / code 8 подготовлена локально. По просьбе владельца «Алмаз» заменён на «Платину», отдельные служебные кнопки и стартовое окно документов убраны, настройки выровнены, исправлена полноэкранная заливка. Документы собраны в «Об игре». Editor — 9877 утверждений, APK — 19/19. На телефон 1.0.6 не устанавливалась: устройство отключено, владелец выбрал подготовку APK. Результаты телефона для 1.0.5 остаются отдельными историческими проверками. Публикация приостановлена до одобрения обновлённого UI. Кабинет 07.11 не проверялся: ранее 1.0.2 / code 4 ожидала модерацию с ручной публикацией, а в отдельном черновике `2064924084` сохранена 1.0.3 / code 5. Этот черновик повторно на модерацию не отправлялся.

## Итоговый объём

В отдельной ветке `codex/rustore-release` сохранены реклама и локальный прогресс. По решению владельца **удалены общий онлайн-рейтинг, Яндекс-вход, LoginSDK и серверная часть из текущего релиза**. Их локальная заготовка отложена, [размещение не требуется](HOSTING.md).

Последняя проверка исходного worktree от 07.11.2026: `67191d12c3f8da09f238595b66a3b0d37bc94676`, отслеживаемые файлы не изменены. Текущая работа ведётся только в отдельном worktree RuStore.

Расширены существующие `YandexBuild`, `GameProgress`, `MainMenuController`, `TopPlayersPanel`, `GameLocalization`, `Ui` и два маршрута Editor-рекламы YG2. Новый код — `Assets/Scripts/RuStore`, `Assets/Editor/YandexBuild.RuStore.cs`, Android Gradle-конфиги и SDK. Игровая механика, графика и экономика не переписывались.
