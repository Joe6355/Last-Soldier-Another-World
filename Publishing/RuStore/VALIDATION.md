# RuStore: первый релиз без сервера

Дата: 30.10.2026. Это подготовка версии; модерация и публикация ещё не выполнены.

## Итоговый объём

В отдельной ветке `codex/rustore-release` сохранены реклама и локальный прогресс. По решению владельца **удалены общий онлайн-рейтинг, Яндекс-вход, LoginSDK и серверная часть из текущего релиза**. Их локальная заготовка отложена, [размещение не требуется](HOSTING.md).

Последняя проверка `main` от 26.10.2026: `67191d12c3f8da09f238595b66a3b0d37bc94676`. Текущая работа ведётся только в отдельном worktree RuStore.

Расширены существующие `YandexBuild`, `GameProgress`, `MainMenuController`, `TopPlayersPanel`, `GameLocalization`, `Ui` и два маршрута Editor-рекламы YG2. Новый код — `Assets/Scripts/RuStore`, `Assets/Editor/YandexBuild.RuStore.cs`, Android Gradle-конфиги и SDK. Игровая механика, графика и экономика не переписывались.

Затем обновлением восстановлен production 1.0.2 / code 4: после холодного запуска баланс 1500. Владелец ранее подтвердил одновременные движение/стрельбу и звук. 29.10.2026 регрессионный тест воспроизвёл удаление активной рекламы по истёкшему showDeadline до обработки очереди SDK. Проверка тайм-аута перенесена в LateUpdate, фон/потеря фокуса исключены из ожидания показа; при возвращении даётся время на callbacks. Награда по-прежнему выдаётся только по OnRewarded. Доказательства локально: `editor-checks-ad-timeout-red-20261029.txt`, `editor-ad-timeout-green-20261029.log`. После исправления все 27 проверок пройдены; это отдельно от проверки реального объявления.

30.10.2026 проверка на физическом телефоне подтвердила выдачу и сохранение настоящей награды после возвращения из native Activity: SDK 8.6.0, обычные `GameMonetization.RequestCoinsForVideo` и `OnRewarded`, без прямого изменения монет тестом. Штатная кнопка закрытия и досрочная отмена на этом устройстве пока не подтверждены. Android Back в отдельных диагностических прогонах не закрывал объявление; такое поведение воспроизведено и в минимальном нативном приложении без Unity. Причина не установлена. Принудительное закрытие Activity, изменение UI SDK, подмена callbacks и понижение SDK в production не применены.
