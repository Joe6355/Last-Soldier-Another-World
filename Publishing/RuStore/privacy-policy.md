Разработчик публикует эту версию под именем Joe6355. Контакт по работе игры и данным: dudin1918@mail.ru.

Игра работает без регистрации. В этой версии нет входа через Яндекс, общего онлайн-рейтинга и собственного сервера профилей. Прогресс, настройки, монеты, инвентарь, достижения и игровая статистика хранятся на вашем устройстве. Облачного переноса сохранений и покупок за реальные деньги нет.

Для удаления локальных данных используйте очистку данных приложения в настройках Android или удаление приложения. Прогресс при этом будет утрачен. Отдельный аккаунт игры не создаётся.

В игре используется Yandex Mobile Ads SDK, включая его компонент AppMetrica. Для загрузки и измерения рекламы SDK может обрабатывать технические сведения об устройстве, сети и показах. Игра устанавливает отсутствие согласия на персонализацию, включает возрастное ограничение сбора данных и отключает отслеживание местоположения. Разрешение Google Advertising ID исключено из манифеста. Эти настройки не означают полного отсутствия технических сетевых данных.

Правила поставщика рекламы: https://yandex.ru/legal/confidential/ и https://yandex.ru/legal/partner_ch/. Реклама загружается после ознакомления с этим уведомлением; для неё нужен интернет. Без сети можно продолжать локальную игру, но рекламные бонусы недоступны.

Политику можно открыть повторно в настройках. Кнопка «Поддержка» открывает ваш почтовый клиент; обращение отправляется только по вашему действию. Для вопросов о данных напишите на dudin1918@mail.ru. Не отправляйте пароли и другие секреты.
