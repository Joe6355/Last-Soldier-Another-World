# Сервер не нужен для первого релиза

Владелец подтвердил выпуск без общего рейтинга и Яндекс-входа при нулевом бюджете. В приложении остаются локальный прогресс и реклама; собственные серверные аккаунты не создаются. VM, домен, облачный аккаунт и регулярная оплата для этого варианта не требуются.

Ранее подготовленные сервер и мосты авторизации сохранены **локально** в ignored `Builds/RuStore/Deferred`; исходный staged-патч — `Builds/RuStoreValidation/online-preparation.patch`. Они не входят в текущую версию GitHub/APK. Облачные ресурсы не создавались, деньги не списывались.

Для возвращения общего рейтинга потребуется отдельное решение по размещению. Бесплатные тарифы существуют с ограничениями; это не обязательный этап текущего релиза.
