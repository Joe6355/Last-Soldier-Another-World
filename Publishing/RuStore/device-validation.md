## Проверка новых меню на телефоне — 06.11.2026, вечер

Явный режим `lastsoldier_ui_check=true` прошёл геометрию и обработчики главного меню, двух входов в редактор кнопок, настроек, диалога имени с отменой, каталога восьми медалей, паузы и игровых настроек. После этого реальным ADB-касанием открыто имя в паузе и через Android-клавиатуру введён выбранный владельцем ник. После подтверждения/сворачивания обнаружена `NullReferenceException` в `TMP_InputField.SendTouchScreenKeyboardStatusChanged`, вызванном из `LateUpdate`. Поэтому одного результата проверки геометрии недостаточно для признания 1.0.4 готовой.

Проверенный исходник TMP 3.0.7 после `OnSubmit` ещё читает `m_SoftKeyboard.status`. Наш обработчик синхронно закрывал и деактивировал окно, обнуляя клавиатуру в том же вызове. В 1.0.5 / code 7 закрытие после keyboard submit перенесено на следующий кадр; обычная кнопка «Сохранить» сохраняет прежний маршрут. Vendor-код TMP не менялся. Добавлен регрессионный сценарий: поле остаётся активным внутри `onSubmit`, а на следующем кадре окно закрывается. Editor-прогон — PASS, 6339 утверждений; локальные доказательства `editor-keyboard-checks-20261106.txt`, `editor-native-keyboard-20261106.log`.

Списки native UI считывались только для пакета игры через существующую probe и системную тестовую библиотеку. Снимки экрана и зеркалирование телефона не использовались. Локальные UI-логи с выбранным именем не предназначены для публикации.
