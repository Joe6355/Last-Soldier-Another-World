## Проверки

- `node Tests/yandex-sdk.test.cjs`: прошёл. Проверяет мост SDK с подставными ответами: облако, вход, рейтинг, ошибки, отмену/награду видео, однократные callbacks и порядок показа баннера.
- В изолированной Unity проверены реальные убийства врагов, завершение волны без повторного бонуса, смерть, отмена/ошибка рекламы, восстановление полного HP, сохранение врагов/таймера, пауза/звук и штраф лагеря.
- Проверено восстановление после перезагрузки сцены при незавершённой смерти: снова доступны видео/лагерь; сохранённая волна начинается заново, повторный бонус не начисляется.
- Проверены попадание UI-raycast в кнопки «Играть», сохранённый callback главного меню, асинхронная загрузка игровой сцены и возобновление игры. Безоконный тест отдельно имитирует возврат фокуса.
- Собрана WebGL-версия; локальные сценарии не подтверждают работу настоящих сервисов Яндекса.

При автоматическом вводе в браузере переход из главного меню в уровень не удалось подтвердить. Ошибок уровня `error` в журнале браузера не найдено; это не подтверждает отсутствие всех проблем. Проверка нажатий в Unity прошла. Перед модерацией нужно вручную пройти игровой сценарий по тестовой ссылке, проверить настоящие rewarded/interstitial, запись MMR и перенос облачного прогресса между устройствами.

Превью `Previews/leaderboard.png` использует тестовые строки. `Previews/death.png` показывает метки редактора. Эти изображения предназначены для проверки интерфейса, не для карточки игры.

## Перед модерацией

| Действие | Состояние |
| --- | --- |
| Завершить договор ЕЛС или РСЯ | Консоль прямо блокирует модерацию без действующего договора; оформление выполняет владелец аккаунта |
| Выбрать возрастной рейтинг | Пока не выбран; требуется проверка сцен насилия и остальных материалов |
| Подготовить иконку и обложку | Поля пусты: PNG 512×512 и 800×470 |
| Добавить горизонтальное видео и скриншоты | Обязательные поля пусты; нужны записи настоящего игрового процесса |
| Подтвердить права на материалы | В репозитории есть лицензия плагина и ссылки на лицензии двух фонов; это не подтверждает права на все спрайты и звук |
| Проверить содержимое | Нужно проверить все текстовые и графические материалы перед отправкой |
| Проверить настоящие облако, рейтинг и рекламу | Через тестовую ссылку после обработки архива; отдельно проверить другой браузер/устройство |

Нативные Windows-сохранения не переносятся автоматически в WebGL. При перезагрузке страницы активная волна начинается заново; продолжение за видео в текущей сессии сохраняет существующих врагов и таймер. Очки рейтинга рассчитывает клиент; отдельного сервера защиты от подмены нет.

В установленном системном Unity пока отсутствует WebGL Build Support. Готовый ZIP получен в изолированной копии официального Unity. Для последующих сборок через меню проекта добавьте этот модуль в Unity Hub.

## Проверка на платформе

Тестовый запуск: [черновик с debug-панелью](https://yandex.ru/games/app/623393?debug-mode=16&draft=true&lang=ru). Ссылка получена из консоли, игра не опубликована.

1. Открыть черновик с debug-панелью. Дождаться меню; проверить Game Ready и индикатор определения языка.
2. Начать игру гостем. Купить предмет/улучшение, перезагрузить страницу: монеты, инвентарь, характеристики и цены должны восстановиться без повторного усиления.
3. Зачистить волну. Проверить прирост MMR: 100 + количество убитых врагов. Истечение таймера с живыми врагами не даёт 100.
4. Умереть. Отменить видео: игрок остаётся на экране выбора. Получить награду видео: полное HP, та же волна, монеты сохранены. Проверить восстановление при перезагрузке этого экрана.
5. Вернуться в лагерь: половина монет, 25 HP. При полноэкранной рекламе игра и звук остановлены; закрытие/ошибка возвращают управление.
6. Открыть меню и рейтинг. Sticky появляется справа средствами платформы; во время игры скрыт. Пустой рейтинг/ошибка сети не блокируют игру.
7. Добровольно войти в пустой Яндекс ID, затем проверить сохранение и MMR с другого устройства. Для аккаунта с существующим прогрессом должен загрузиться его прогресс.
8. Переключить вкладку, изменить размер окна, повторить проверки в доступных браузерах.
