## Проверка ответа записи 0.0.0.6

В 0.0.0.5 настоящий `setScore('mmr', 1707, ...)` разрешился в 18:52:07.190 UTC 13 октября; `getPlayerEntry` в 18:52:07.321 UTC вернул `LEADERBOARD_PLAYER_NOT_PRESENT`. После перезагрузки запись снова разрешилась в 18:55:04.088 UTC, чтение в 18:55:04.136 UTC вернуло ту же ошибку. Это подтверждает отсутствие читаемой записи в моменты запросов, но не доказывает успешное сохранение или конкретную причину. Журнал: [leaderboard-platform-check.json](leaderboard-platform-check.json).

В публичном JS родительской страницы Яндекса `setLeaderboardScore` разбирает JSON при HTTP-ответе не 204, обходя проверку HTTP-статуса. Поэтому JSON ошибки может разрешить Promise SDK. Версия 0.0.0.6 распознаёт ответы `error` либо `reason` + `message` как ошибку записи; журналирует только тип ответа, названия полей и код ошибки. При отсутствующей записи выполняет ещё одно чтение через 60 секунд без нового `setScore`. Пока связь найденного пути с текущим пустым рейтингом не установлена.

После подтверждённой записи выполняется один `getPlayerEntry`; ошибка диагностического чтения не отменяет подтверждение. Имена и ID в эти сообщения не попадают.

Нативные Windows-сохранения не переносятся автоматически в WebGL. При перезагрузке страницы активная волна начинается заново; продолжение за видео в текущей сессии сохраняет существующих врагов и таймер. Очки рейтинга рассчитывает клиент; отдельного сервера защиты от подмены нет.

В установленном системном Unity 2022.3.47f1 отсутствует WebGL Build Support. Новый ZIP получен в отдельной копии того же официального редактора с официальным модулем WebGL: `Builds/U22/Editor/Unity.exe`. Восстановленные вспомогательные скрипты находятся в `Builds/WebGLRuntimeTools`; MD5 скачанного модуля проверен по установленному `modules.json`. Эти каталоги исключены из Git. Для сборок системным редактором установите модуль через Unity Hub.

## Проверка на платформе

Тестовый запуск: [черновик с debug-панелью](https://yandex.ru/games/app/623393?debug-mode=16&draft=true&lang=ru). Ссылка получена из консоли, игра не опубликована.

1. Открыть черновик с debug-панелью. Дождаться меню; проверить Game Ready и индикатор определения языка.
2. Начать игру гостем. Купить предмет/улучшение, перезагрузить страницу: монеты, инвентарь, характеристики и цены должны восстановиться без повторного усиления.
3. Зачистить волну. Проверить прирост MMR: 100 + количество убитых врагов. Истечение таймера с живыми врагами не даёт 100.
4. Умереть. Отменить видео: игрок остаётся на экране выбора. Получить награду видео: полное HP, та же волна, монеты сохранены. Проверить восстановление при перезагрузке этого экрана.
5. Вернуться в лагерь: половина монет, 25 HP. При полноэкранной рекламе игра и звук остановлены; закрытие/ошибка возвращают управление.
6. Открыть меню и рейтинг. Sticky появляется справа средствами платформы; во время игры скрыт. Пустой рейтинг/ошибка сети не блокируют игру.
7. Добровольно войти в пустой Яндекс ID, затем проверить сохранение и MMR с другого устройства. Для аккаунта с существующим прогрессом должен загрузиться его прогресс.
8. Переключить вкладку, изменить размер окна, повторить проверки в доступных браузерах.
