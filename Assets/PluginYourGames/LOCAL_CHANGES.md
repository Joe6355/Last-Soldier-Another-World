# Подключение Last Soldier

Исходная версия: Plugin Your Games 2.0092, https://github.com/JustPlay-Max/Unity-PluginYG-2/releases/tag/2.0092.
Базовая часть импортирована из unitypackage; восемь модулей — из исходников того же релиза. Примеры не импортированы. Реклама: InterstitialAdv, RewardedAdv, StickyAdv.

Локальные изменения, которые нужно сохранить при обновлении плагина:

- `PlatformSettings.cs`: импорт UnityEditor защищён `UNITY_EDITOR` для сборки игрока.
- `CloudStorage_js.js` и `GameCloudStatus.jslib`: различаются отсутствие сохранения и ошибка загрузки; проверяется формат данных, ожидается Promise записи и сообщается результат в GameProgress.
- `Auth_js.js`: отмена/ошибка входа сообщает `GameAuthClosed`, чтобы разблокировать гостевой запуск.
- `LB_js.js`: ожидается Promise записи рейтинга, проверяется доступность отправки; ошибки чтения сообщаются в GameProgress. Имя берётся из `player.publicName`, индекс цикла локальный, тип и сортировка читаются из актуального формата SDK.
- `Storage_yg.cs`: файлы симуляции облака в Editor разделены для гостя и пользователя.
- `RewardedAdv_js.js`: награда выдаётся один раз; повторные/поздние callbacks не выдают её снова. Ошибка, исключение или отсутствие SDK завершают ожидание и снимают паузу через callback закрытия.
- `InterAdv_js.js`: параллельные запросы блокируются до открытия; ошибка/исключение закрывают ожидание один раз с `wasShown=false`.
- `StickyAdv_js.js`: последовательные запросы учитывают последнюю запрошенную видимость; асинхронный show не отменяет более поздний hide.

Настройки `Resources/SettingsYG2.asset` отключают автоматическую смену настроек проекта, автогенерацию defines и автоматический GameReadyAPI. Готовность объявляет игровое меню после восстановления прогресса. Лидерборд — `mmr`, decimalOffset=0, симуляция не содержит вымышленных участников. Автоматическая первая реклама отключена, интервал interstitial 60 секунд; шаблон фиксирует 16:9. Локальные резервные копии с разделением аккаунтов и ограничения частоты запросов находятся в `Assets/Scripts/Yandex/GameProgress.cs`, игровые точки рекламы — в `GameMonetization.cs`.
